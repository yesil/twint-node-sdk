Integration Example

1. Usage

<pay-with-twint 
  reference="ORDER-123"
  amount="99.95"
  api-url="/api"
  theme="light"
  confirmation-needed="true">
</pay-with-twint>

2. Available Events

// Component events:
- payment-started
- payment-completed
- payment-failed
- payment-cancelled
- status-changed
- payment-error

// Example listener:
payment.addEventListener('status-changed', (e) => {
  console.log('Status:', e.detail.status);
});
